# Security Policy

## Reporting a vulnerability

Please report security issues privately to Amhita Marouane.

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/Amhitox/nager-holidays-sdk/issues

## Scope

This policy applies to the generated Amhita Marouane SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Community - API V4 public API, generated by
Amhita Marouane. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
